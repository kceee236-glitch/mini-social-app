# Kcee Chatify 🚀

> A sleek, real-time micro-social chat application allowing users to broadcast public messages instantly.

**[Live Demo: Click here to use Kcee Chatify](https://kceechatify.netlify.app/)**

## 📖 About This Project
Kcee Chatify is a lightweight, full-stack micro-social feed. It was built to demonstrate decoupled web architecture, combining a vanilla frontend with a robust REST API backend. The UI is inspired by modern dark-mode applications, ensuring a fully responsive and clean mobile-first experience. 

## ✨ Features
* **Real-Time Public Feed:** View and post messages instantly to a global public timeline.
* **Modern Dark-Mode UI:** Sleek, responsive design that works seamlessly on desktop and mobile devices.
* **Decoupled Architecture:** Built with a separated frontend and backend API for optimal performance.
* **Security First:** Implements backend text escaping and parameterized SQL queries to prevent XSS and SQL injection attacks.

## 🛠️ Tech Stack
**Frontend:**
* HTML5 & CSS3 (Custom Google Fonts)
* Vanilla JavaScript (ES6+)
* Fetch API for dynamic data rendering
* Hosted on **Netlify**

**Backend:**
* Node.js & Express.js
* REST API routing
* Hosted on **Render**

**Database:**
* SQLite3
